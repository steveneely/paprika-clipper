# Bundled typography

Montserrat is distributed unchanged from the Google Fonts repository under the SIL Open Font License 1.1. Its license is included in OFL-Montserrat.txt.

Source: https://github.com/google/fonts/blob/main/ofl/montserrat/Montserrat%5Bwght%5D.ttf
Retrieved: 2026-09-11

Futura is referenced as a locally installed font only. No Futura or Adobe Typekit font files are included. Where Futura is unavailable, the brand text falls back to bundled Montserrat.

No external font services are contacted at runtime.
